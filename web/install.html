ЛОКАЛЬНАЯ УСТАНОВКА · WINDOWS

ЗАПУСТИ ЕГОНА СВОЁМ КОМПЬЮТЕРЕ

Скачай архив, распакуй, двойной клик — и Джарвис будет жить у тебя: сам поставит Python, поднимет сервер с HUD, подключит агент управления ПК, добавит автозагрузку и откроет браузер. Никаких команд и ручных настроек.

Облачный предпросмотр выключен? Это нормально: ссылки /download/… выше работают, только пока открыт этот HUD. Всегда используйте «АРХИВ С GITHUB» или откройте offline-инструкцию из распакованного архива — она не зависит от песочницы.

ТРИ ШАГА

1

Скачай и распакуй

Нажми большую кнопку выше. Правый клик по архиву → «Извлечь все…». Папка может быть где угодно.

JARVIS-Windows.zip → Распаковать
2

Двойной клик

Запусти INSTALL_WINDOWS.bat. Если SmartScreen ругается — «Дополнительные сведения» → «Выполнить в любом случае».

INSTALL_WINDOWS.bat ⏎ ~30 сек
3

Разреши микрофон

Браузер откроется сам. Нажми «Активировать систему», разреши микрофон в Chrome / Edge и скажи «Джарвис, который час?».

http://127.0.0.1:8080

ЧТО ОН СДЕЛАЕТ САМ

  • Найдёт или установит Python 3.9+ (winget → официальный установщик)
  • Скопирует приложение в %LOCALAPPDATA%\JARVIS
  • Запустит сервер HUD и агент управления ПК скрытно, без чёрных окон
  • Подключит агент — «открой блокнот» будет выполняться на твоей машине
  • Добавит автозагрузку, ярлык на рабочий стол и иконку в трей
  • Проверит готовность сервера, агента и русский голос для озвучки
  • Слушает только 127.0.0.1 — доступен лишь с твоего ПК
  • Опасные команды и выключение ПК запрещены по умолчанию

НЕ ХОЧЕШЬ УСТАНАВЛИВАТЬ? ПОДКЛЮЧИ ТОЛЬКО СВОЙ ПК

Оставь этот HUD в облаке, а команды пусть выполняются у тебя

Скачай один файл jarvis_agent.py и запусти на своём компьютере. В HUD сразу загорится «ПК подключён».

python jarvis_agent.py --server ...
Важно: в этом режиме заметки, задачи и настройки хранятся на облачном сервере, а не у тебя. Для полной автономности используй установщик выше.

НЕ WINDOWS

Linux и macOS: клонируй репозиторий и запусти двумя командами.

git clone -b arena/57b8f59e-assistent-ai https://github.com/Sevelin123/ASSISTENT-AI.git && cd ASSISTENT-AI && python3 jarvis.py

Затем http://localhost:8080. Для управления ПК во втором терминале: python3 jarvis_agent.py --server http://localhost:8080

ЧАСТЫЕ ВОПРОСЫ

Нужен ли API-ключ?

НЕТ. Установщик создаёт конфиг без ключей, и Джарвис сразу работает оффлайн: 35 действий, голос, заметки, задачи, файлы, расчёты и управление ПК. Ключ — только опциональный «мозг» для свободных разговоров с внешней LLM.

Хотите подключить? Настройки → Мозг · Языковая модель. Самый простой путь без ключа и без интернета — Ollama: ollama pull llama3.1 → ollama serve → пресет Ollama (локально) → сохранить. Для облака нужен ваш ключ: Groq (бесплатный тариф, из РФ может блокироваться) или OpenAI (РФ нет в официальном списке). Для РФ обычно берут Ollama или OpenAI-совместимый агрегатор вроде GPTunnel / ProxyAPI: его endpoint, модель и ключ указаны в личном кабинете. Ключ хранится только локально и не попадает в git/логи.

Я ключ не выдаю: он создаётся в личном кабинете провайдера. Если оставить поле пустым — ничего не сломается, останется МОЗГ: OFFLINE NLU.

«Языковая модель недоступна» / 403 Forbidden

Приложение не сломалось. Это ответ внешнего провайдера LLM: доступ запрещён. Джарвис уже работает через оффлайн-NLU. В HUD нажмите «Работать оффлайн» или снимите галочку Настройки → Мозг → Использовать языковую модель — ключ после этого не нужен.

Хотите починить облачную модель? Проверьте ключ у того же провайдера, права/баланс, endpoint с /v1, точное имя модели и доступность региона. OpenAI трактует 403 как неподдерживаемую страну/регион в справочнике ошибок; у Groq 403 — ограничение прав по документации. Для РФ надёжнее Ollama без ключа или доступный OpenAI-совместимый агрегатор. Если 403 пришёл от локального Ollama — проверьте ollama serve, порт 11434, Host: localhost:11434 и OLLAMA_ORIGINS: сам локальный сервер ключа не требует.

Ключ не присылайте в чат: диагностика показывает только код ошибки и подсказку, но не секрет.

Не удаётся связаться с сервером / ERR_CONNECTION_REFUSED

1. Откройте именно http://127.0.0.1:8080 — не localhost:8080 (на Windows он часто уходит в IPv6 ::1), не file://.../web/index.html и не старую ссылку *.e2b.app. HUD работает только через локальный сервер.

2. Если ещё не устанавливали — INSTALL_WINDOWS.bat. Браузер сам сервер не запускает: ERR_CONNECTION_REFUSED означает «ничего не слушает порт 8080», а не «нет интернета».

3. Хотите увидеть ошибку глазами — START-JARVIS.bat. Откроется консоль с сервером; не закрывайте её, иначе связь снова пропадёт. Автоматическая починка: FIX-SERVER.bat — проверит Python и порт, покажет владельца, перезапустит сервер и агент, запишет логи.

4. Порт занят? START-JARVIS.bat -Port 9000 или FIX-SERVER.bat -Port 9000 → http://127.0.0.1:9000. Полная переустановка: INSTALL_WINDOWS.bat -Port 9000. Логи: %LOCALAPPDATA%\JARVIS\logs\server.err.log.

5. Консоль пишет online, а Chrome всё равно отказывает? Отключите прокси для локальных адресов (Параметры → Система → Прокси, исключения 127.0.0.1;localhost) или запустите Chrome с --no-proxy-server. Фраза Chrome про интернет/брандмауэр здесь шаблонная.

В HUD при обрыве связи появляется красная плашка с диагностикой и кнопками «START-JARVIS.bat», «FIX-SERVER.bat», «Архив с GitHub», «Повторить».

502 BAD GATEWAY / SANDBOX NOT FOUND — облачная ссылка умерла

Это не поломка Джарвиса: временная песочница-предпросмотр выключена, поэтому шлюз не находит её. Не пытайтесь «починить» старую ссылку https://8080-….e2b.app.

Что делать: нажмите «АРХИВ С GITHUB · ВСЕГДА АКТУАЛЬНЫЙ» выше (или откройте прямую ссылку), распакуйте и двойным кликом запустите INSTALL_WINDOWS.bat. В архиве есть START-HERE.html — автономная инструкция, которую можно открыть без сервера.

После установки используйте только свой адрес http://127.0.0.1:8080 или ярлык на рабочем столе. Облако больше не нужно.

Окно мигает и сразу закрывается

Запусти BAT из cmd, чтобы увидеть ошибку. Подробный лог: %LOCALAPPDATA%\JARVIS\install.log и logs\server.log.

Русский язык / голос НЕ СТАВИТСЯ в Параметрах речи Windows

Сначала важное: чтобы Джарвис понимал русскую речь, языковой пакет Windows не нужен — распознавание делает браузер (Chrome/Edge) через Web Speech API. Язык задаётся в HUD: Настройки → Голос и речь → Язык распознавания → Русский (ru-RU). Проблема с «Параметрами речи» влияет только на озвучивание ответов.

Путь 1 — отдельный голос (быстрее всего). Win+I → Время и язык → Речь → Управление голосами → Добавить голоса → Русский (Россия) → Добавить. Нужны права администратора и Windows 11 22H2+; если кнопка серая — сначала Центр обновления Windows, затем перезагрузка.

Путь 2 — через языковой пакет. Время и язык → Язык и регион → Добавить язык → Русский → Далее и обязательно отметьте «Преобразование текста в речь» / Text-to-speech (и «Распознавание речи», если есть). Если язык уже добавлен, но галочки нет: троеточие рядом с «Русский» → Параметры языка → Добавить компонент → скачать Speech/Text-to-speech.

Если не ставится — проверьте по порядку:

· Win+R → winver — если написано Home Single Language, добавить второй языковой пакет нельзя в принципе (ограничение лицензии). Обходной путь ниже.
· Учётная запись должна быть Администратор, рабочие/учебные ПК часто блокируют загрузку политиками.
· Регион: Время и язык → Язык и регион → Страна или регион → Россия; язык, регион и язык речи должны совпадать.
· Обновите Windows, отключите VPN/лимитное соединение, перезагрузитесь.
· Удалите русский язык из списка, перезагрузитесь, добавьте заново со всеми галочками.
· От админа: DISM /Online /Cleanup-Image /RestoreHealth → sfc /scannow → перезагрузка (чинит пакеты голосов «0 КБ»).
· Set-WinUserLanguageList ru-RU -Force в PowerShell добавит раскладку, но не голос — это помогает только с вводом.

Обходной путь, который работает почти всегда: откройте HUD в Microsoft Edge — у него есть облачные голоса «Microsoft … Online (Natural)», включая русские, без языкового пакета Windows; у Chrome есть сетевые «Google русский». Голоса подгружаются асинхронно, поэтому полностью закройте и откройте браузер заново, затем в HUD: Настройки → Голос и речь → Обновить список → Голос ответа → русский → Тест речи. Если системных голосов ноль, HUD сам покажет это в диагностике.

Ещё варианты: поставить сторонний SAPI-голос (например, RHVoice), либо вообще выключить озвучивание голосом: «Джарвис, выключи озвучивание» — ответы останутся текстом.

Порт 8080 занят / хочу другой

INSTALL_WINDOWS.bat -Port 9000. Доступ с телефона: -Lan, затем ipconfig → http://IP:8080.

Как обновить или удалить

Обновление: запусти INSTALL_WINDOWS.bat заново — заметки и настройки сохранятся. Удаление: UNINSTALL_WINDOWS.bat (данные останутся), с -Purge — удалит всё.

Нужен ли интернет после установки?

Само приложение — нет: Python, сервер, заметки, файлы и агент работают полностью локально. Интернет нужен только браузерному распознаванию речи и (по желанию) облачной языковой модели. Для полностью оффлайн-голоса можно подключить локальный Vosk/Whisper — см. README.
