ЛОКАЛЬНАЯ УСТАНОВКА · WINDOWS

ЗАПУСТИ ЕГОНА СВОЁМ КОМПЬЮТЕРЕ

Скачай архив, распакуй, двойной клик — и Джарвис будет жить у тебя: сам поставит Python, поднимет сервер с HUD, подключит агент управления ПК, добавит автозагрузку и откроет браузер. Никаких команд и ручных настроек.

↓ СКАЧАТЬ УСТАНОВЩИК (.ZIP) ↓ ТОЛЬКО .BAT АРХИВ С GITHUB · ВСЕГДА АКТУАЛЬНЫЙ

Версия 1.0.0 · Windows 10/11 · ~120 КБ · только стандартная библиотека Python · данные остаются локально

ТРИ ШАГА

1

Скачай и распакуй

Нажми большую кнопку выше. Правый клик по архиву → «Извлечь все…». Папка может быть где угодно.

JARVIS-Windows.zip → Распаковать
2

Двойной клик

Запусти INSTALL_WINDOWS.bat. Если SmartScreen ругается — «Дополнительные сведения» → «Выполнить в любом случае».

INSTALL_WINDOWS.bat ⏎ ~30 сек
3

Разреши микрофон

Браузер откроется сам. Нажми «Активировать систему», разреши микрофон в Chrome / Edge и скажи «Джарвис, который час?».

http://127.0.0.1:8080

ЧТО ОН СДЕЛАЕТ САМ

  • Найдёт или установит Python 3.9+ (winget → официальный установщик)
  • Скопирует приложение в %LOCALAPPDATA%\JARVIS
  • Запустит сервер HUD и агент управления ПК скрытно, без чёрных окон
  • Подключит агент — «открой блокнот» будет выполняться на твоей машине
  • Добавит автозагрузку, ярлык на рабочий стол и иконку в трей
  • Проверит готовность сервера, агента и русский голос для озвучки
  • Слушает только 127.0.0.1 — доступен лишь с твоего ПК
  • Опасные команды и выключение ПК запрещены по умолчанию

НЕ ХОЧЕШЬ УСТАНАВЛИВАТЬ? ПОДКЛЮЧИ ТОЛЬКО СВОЙ ПК

Оставь этот HUD в облаке, а команды пусть выполняются у тебя

Скачай один файл jarvis_agent.py и запусти на своём компьютере. В HUD сразу загорится «ПК подключён».

python jarvis_agent.py --server ...
Важно: в этом режиме заметки, задачи и настройки хранятся на облачном сервере, а не у тебя. Для полной автономности используй установщик выше.

НЕ WINDOWS

Linux и macOS: клонируй репозиторий и запусти двумя командами.

git clone -b arena/57b8f59e-assistent-ai https://github.com/Sevelin123/ASSISTENT-AI.git && cd ASSISTENT-AI && python3 jarvis.py

Затем http://localhost:8080. Для управления ПК во втором терминале: python3 jarvis_agent.py --server http://localhost:8080

ЧАСТЫЕ ВОПРОСЫ

Окно мигает и сразу закрывается

Запусти BAT из cmd, чтобы увидеть ошибку. Подробный лог: %LOCALAPPDATA%\JARVIS\install.log и logs\server.log.

Голос не работает / нет русской озвучки

Распознавание речи требует Chrome или Edge и интернета (браузерный Web Speech API). Для озвучки добавь русский голос: Параметры → Время и язык → Речь → Добавить голоса → Русский. Установщик сам предупредит, если его нет.

Порт 8080 занят / хочу другой

INSTALL_WINDOWS.bat -Port 9000. Доступ с телефона: -Lan, затем ipconfig → http://IP:8080.

Как обновить или удалить

Обновление: запусти INSTALL_WINDOWS.bat заново — заметки и настройки сохранятся. Удаление: UNINSTALL_WINDOWS.bat (данные останутся), с -Purge — удалит всё.

Нужен ли интернет после установки?

Само приложение — нет: Python, сервер, заметки, файлы и агент работают полностью локально. Интернет нужен только браузерному распознаванию речи и (по желанию) облачной языковой модели. Для полностью оффлайн-голоса можно подключить локальный Vosk/Whisper — см. README.
