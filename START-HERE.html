Этот файл лежит прямо в архиве. Откройте его двойным кликом — и выполняйте шаги ниже. Ни песочница, ни предпросмотр, ни временная ссылка *.e2b.app больше не нужны.

Видите в Chrome «Не удается получить доступ к сайту» / ERR_CONNECTION_REFUSED на 127.0.0.1:8080?
Это значит ровно одно: на вашем ПК сейчас не запущен сервер J.A.R.V.I.S. Фразы Chrome про «интернет, прокси и брандмауэр» — общий шаблон; для адреса 127.0.0.1 интернет не нужен. Обновлять страницу бесполезно: сначала двойной клик по START-JARVIS.bat (или INSTALL_WINDOWS.bat, если ещё не устанавливали) и не закрывайте чёрное окно консоли.
Видите «502 BAD GATEWAY / SANDBOX NOT FOUND»?
Это означает только одно: временная облачная песочница выключена. Само приложение и установщик от этого не зависят. Игнорируйте старую ссылку вида https://8080-….e2b.app и используйте архив с GitHub ниже. После установки вы будете открывать свой адрес: http://127.0.0.1:8080.
Главная ссылка, которая работает всегда: архив собирается прямо из ветки репозитория на GitHub. Даже если облачный предпросмотр недоступен, эта ссылка остаётся.

ТРИ ШАГА · WINDOWS 10 / 11

1

Распакуйте архив

Правый клик по .zip → «Извлечь все…». Внутри будет INSTALL_WINDOWS.bat, папка windows\ и этот файл START-HERE.html.

2

Двойной клик по INSTALL_WINDOWS.bat

Если Windows SmartScreen покажет предупреждение: «Дополнительные сведения» → «Выполнить в любом случае». Установщик сам найдёт или поставит Python 3.9+, скопирует приложение в %LOCALAPPDATA%\JARVIS, создаст ярлык, автозагрузку и иконку в трее.

3

Откройте свой локальный HUD

Через ~30 секунд браузер сам откроет http://127.0.0.1:8080. Разрешите микрофон, нажмите «Активировать систему» и скажите: «Джарвис, который час?». Используйте Chrome или Edge.

Готово. Дальше облако не участвует: сервер и агент крутятся на вашем компьютере, заметки/задачи хранятся локально в SQLite. Ярлык «J.A.R.V.I.S.» лежит на рабочем столе.

«НЕ УДАЁТСЯ СВЯЗАТЬСЯ С СЕРВЕРОМ»

Сначала проверьте адрес. Откройте именно http://127.0.0.1:8080. Не localhost:8080 (на Windows он часто уходит в IPv6 ::1), не file://.../web/index.html, не старую ссылку *.e2b.app и не адрес облачного предпросмотра. HUD должен открываться через локальный сервер.
0

Если ещё не устанавливали — INSTALL_WINDOWS.bat

Браузер сам сервер не запускает. Двойной клик по INSTALL_WINDOWS.bat, дождитесь «УСТАНОВКА ЗАВЕРШЕНА», и только потом открывайте http://127.0.0.1:8080.

▶

Видите ошибку в консоли? START-JARVIS.bat

Двойной клик по START-JARVIS.bat запускает сервер в видимом окне: сразу видно, если не найден Python, занят порт или упал импорт. Оставьте окно открытым — закрытие консоли останавливает сервер и снова даёт ERR_CONNECTION_REFUSED. Для другого порта: START-JARVIS.bat -Port 9000.

✚

Автоматическая починка: FIX-SERVER.bat

Он сам найдёт Python, прочитает порт из jarvis.config.json, покажет, кто занимает порт, остановит зависшие процессы J.A.R.V.I.S., заново поднимет сервер и агент скрытно, проверит /api/health и откроет браузер. Логи — в папке logs\.

!

Если порт 8080 занят

Запустите FIX-SERVER.bat -Port 9000 и откройте http://127.0.0.1:9000. Полностью переустановить можно повторным запуском INSTALL_WINDOWS.bat -Port 9000.

Сервер в консоли пишет «online», а Chrome всё равно отказывает? Проверьте прокси: Параметры → Система → Настройки прокси-сервера → включите «Не использовать прокси-сервер для локальных адресов» / добавьте 127.0.0.1;localhost в исключения. Либо запустите Chrome с ярлыка chrome.exe --no-proxy-server. Брандмауэр почти никогда не блокирует loopback, но антивирус с «защитой веб-трафика» — может.

В HUD при потере связи теперь появляется красная плашка с кнопками «FIX-SERVER.bat», «Архив с GitHub» и «Повторить», а в сообщении объясняется, что именно не так: file://, localhost, мёртвое облако или выключенный локальный сервер.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

Нужен ли API-ключ?

НЕТ, не нужен. Джарвис уже работает без него: голосовые команды, 35 действий, заметки, задачи, напоминания, калькулятор, файлы, системная информация и реальное управление ПК через агент — всё это встроенный оффлайн-NLU. Фраза «добавьте ключ для ответов на любые вопросы» означает лишь необязательный режим внешней языковой модели.

Хотите всё-таки подключить LLM? В HUD: Настройки → Мозг · Языковая модель.

· Проще и без ключа: установить Ollama, выполнить ollama pull llama3.1 и ollama serve, выбрать пресет Ollama (локально), поле ключа оставить пустым, сохранить. Endpoint http://localhost:11434/v1.
· Облачный бесплатный тариф: ключ console.groq.com/keys, endpoint https://api.groq.com/openai/v1, модель llama-3.1-8b-instant. Из РФ прямой доступ к Groq может блокироваться — проверьте у себя.
· OpenAI: ключ platform.openai.com/api-keys, но Россия не входит в официальный список поддерживаемых стран. ChatGPT Plus ≠ API-ключ, у API отдельная оплата.
· Для РФ: используйте Ollama или OpenAI-совместимый агрегатор, доступный в вашем регионе — например GPTunnel / ProxyAPI. Endpoint, имя модели и ключ берутся из его личного кабинета; в полях HUD введите их вместо пресета OpenAI.

Ключ я не выдаю — он создаётся в вашем личном кабинете. Он хранится только в локальном jarvis.config.json, не возвращается браузеру через /api/config, не пишется в логи и не попадает в git. Если включить облачный пресет без ключа, приложение не сломается — останется оффлайн и покажет подсказку.

Русский язык / голос не ставится в Параметрах Windows

Распознаванию речи это не мешает. Джарвис понимает русскую речь через браузерный Web Speech API (Chrome/Edge), а не через языковой пакет Windows. Язык задаётся в HUD: Настройки → Голос и речь → Язык распознавания → Русский (ru-RU).

Для озвучки ответов проще всего открыть HUD в Microsoft Edge: там есть облачные голоса Microsoft … Online (Natural) без установки языкового пакета. Затем: Обновить список → Голос ответа → русский → Тест речи. Полностью перезапустите браузер после установки новых голосов.

Хотите системный голос: Win+I → Время и язык → Речь → Управление голосами → Добавить голоса → Русский (Россия). Если не ставится — проверьте winver (редакция Home Single Language не даёт добавить пакет), права администратора, регион «Россия», обновления Windows, а от админа выполните DISM /Online /Cleanup-Image /RestoreHealth и sfc /scannow. Подробная шпаргалка создаётся установщиком: %LOCALAPPDATA%\JARVIS\VOICE-HELP.txt.

Озвучку можно вообще отключить: скажите «Джарвис, выключи озвучивание» — ответы останутся текстом.

Окно установщика мигает и закрывается

Запустите BAT из cmd, чтобы увидеть ошибку. Логи: %LOCALAPPDATA%\JARVIS\install.log, %LOCALAPPDATA%\JARVIS\logs\server.log и logs\agent.log.

ERR_CONNECTION_REFUSED / «Не удаётся связаться с сервером»

Это значит, что python jarvis.py не слушает порт. Откройте http://127.0.0.1:8080 (не localhost) и запустите START-JARVIS.bat — оставьте консоль открытой. Автоматический вариант — FIX-SERVER.bat. Если в logs\server.err.log написано «Address already in use» — порт занят, используйте -Port 9000. Если Python не найден — перезапустите INSTALL_WINDOWS.bat.

Ссылка на предпросмотр снова не открывается

Это нормально: https://8080-….e2b.app — лишь временная демонстрация. Для постоянной работы используйте http://127.0.0.1:8080 после установки или ярлык на рабочем столе. Скачивать что-либо заново из песочницы не нужно.

Хочу запустить без установщика / не на Windows

Linux, macOS или ручной запуск на Windows:

git clone -b arena/57b8f59e-assistent-ai https://github.com/Sevelin123/ASSISTENT-AI.git
cd ASSISTENT-AI
python3 jarvis.py

Затем http://localhost:8080. Для реальных действий с ПК во втором терминале: python3 jarvis_agent.py --server http://localhost:8080.

Удалить / обновить

UNINSTALL_WINDOWS.bat удалит приложение, но сохранит настройки и базу. UNINSTALL_WINDOWS.bat -Purge удалит всё. Повторный запуск INSTALL_WINDOWS.bat обновляет файлы, сохраняя jarvis.config.json и SQLite.

Параметры: -Port 9000, -Lan, -NoAutostart, -NoTray, -NoLaunch.
