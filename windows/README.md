# Автоматическая установка J.A.R.V.I.S. на Windows

**Один двойной клик — и всё готово.** Установщик сам найдёт/поставит Python, развернёт приложение, поднимет сервер и агент управления ПК, добавит автозагрузку, создаст ярлыки и откроет HUD в браузере.

## Способ 1 (рекомендуемый) — архив с GitHub, без облачного HUD

1. Скачайте **[актуальный архив ветки](https://codeload.github.com/Sevelin123/ASSISTENT-AI/zip/refs/heads/arena/57b8f59e-assistent-ai)**.
2. Распакуйте архив в любую папку.
3. Откройте **`START-HERE.html`** двойным кликом — это автономная инструкция, она работает без сервера.
4. Двойной клик по **`INSTALL_WINDOWS.bat`**.
5. Через ~30 секунд откроется браузер с HUD. Скажите **«Джарвис, который час?»**.

Если запущен облачный предпросмотр, можно также открыть `/install` и нажать «Скачать установщик Windows (.zip)». Но **`502 BAD GATEWAY / SANDBOX NOT FOUND` означает, что песочница выключена** — в этом случае используйте только ссылку на GitHub выше и `START-HERE.html`. После установки облако не нужно: открывайте **именно** `http://127.0.0.1:8080`.

> **Не `localhost:8080`.** Установщик по умолчанию привязывает сервер к `127.0.0.1`, а `localhost` на Windows часто резолвится в IPv6 `::1` — тогда браузер пишет «Не удаётся связаться с сервером». Не открывайте и `web/index.html` как файл: HUD должен грузиться с локального сервера.

## «Не удаётся связаться с сервером» / `ERR_CONNECTION_REFUSED`

`ERR_CONNECTION_REFUSED` означает: **на порту 8080 сейчас никто не слушает**. Подсказки Chrome про интернет/прокси — шаблон; для `127.0.0.1` интернет не нужен.

0. **ЕслиINSTALL_WINDOWS.bat ещё не запускали — запустите его.** Браузер сам сервер не поднимает. Обновление страницы до этого бесполезно.
1. Откройте `http://127.0.0.1:8080` (или другой порт, если ставили с `-Port`).
2. **Видимый режим: `START-JARVIS.bat`.** Двойной клик → консоль с сервером, сразу видны ошибки Python/порта. **Не закрывайте окно**: закрытие = остановка сервера = снова `ERR_CONNECTION_REFUSED`. `START-JARVIS.bat -Port 9000` для другого порта.
3. **Автоматический режим: `FIX-SERVER.bat`** — лежит в корне архива, копируется в `%LOCALAPPDATA%\JARVIS` и получает ярлык **«Починить связь с сервером»** в меню «Пуск». Скрипт `windows\fix-server.ps1`:
   - берёт порт из `jarvis.config.json` (по умолчанию 8080);
   - находит Python (`py -3`, `python`, `python3`, стандартные папки установки);
   - показывает, какой PID слушает порт (`Get-NetTCPConnection` / `netstat`);
   - останавливает только зависшие процессы `jarvis.py` / `jarvis_agent.py`;
   - заново запускает сервер на `127.0.0.1` и агента скрытно, с логами в `logs\`;
   - ждёт `/api/health` до ~21 секунды и открывает браузер.
4. Порт занят другой программой: `START-JARVIS.bat -Port 9000` или `FIX-SERVER.bat -Port 9000` → `http://127.0.0.1:9000`. Не нужно вручную править конфиг.
5. **Консоль пишет `online`, а Chrome отказывает:** отключите прокси для локальных адресов (`Параметры → Система → Прокси`, исключения `127.0.0.1;localhost`) или запустите `chrome.exe --no-proxy-server`. Антивирус с перехватом веб-трафика тоже может мешать loopback.
6. Логи: `%LOCALAPPDATA%\JARVIS\logs\server.out.log`, `server.err.log`, `agent.err.log`, `install.log`.
7. Если Python не найден — перезапустите `INSTALL_WINDOWS.bat` (он поставит Python через winget или официальный тихий установщик).

Параметры: `FIX-SERVER.bat -Port 9000 -NoLaunch -NoAgent`, `START-JARVIS.bat -Port 9000`. В HUD при обрыве связи появляется красная плашка с диагнозом и кнопками `START-JARVIS.bat` / `FIX-SERVER.bat`.

## Способ 3 — один BAT-файл

Скачайте только `INSTALL_WINDOWS.bat` (кнопка в HUD или `/download/INSTALL_WINDOWS.bat`), запустите его. Он сам скачает исходники с GitHub, выбрав актуальную ветку, и проведёт установку. Нужен интернет.

---

## Что именно делает установщик

| Шаг | Действие |
|---|---|
| 1 | Проверяет Python 3.9+ (`py`, `python`, стандартные папки). Если нет — ставит через **winget**, при отсутствии winget — тихий официальный установщик с python.org |
| 2 | Копирует приложение в `%LOCALAPPDATA%\JARVIS\app` (данные и `jarvis.config.json` не перезаписываются при обновлении) |
| 3 | Создаёт конфиг: `ru-RU`, wake word «джарвис», опасные действия **запрещены** |
| 4 | Генерирует скрытые запускатели `run-server.cmd`, `run-agent.cmd`, `start-background.vbs` — без чёрных консольных окон |
| 5 | Рисует иконку `jarvis.ico` и создаёт ярлыки: рабочий стол, меню «Пуск», автозагрузка |
| 6 | Запускает иконку в системном трее: состояние ядра/агента, «Открыть», «Перезапустить», «Остановить», «Логи» |
| 7 | Ждёт `/api/health`, проверяет подключение агента, проверяет наличие русского голоса TTS |
| 8 | Открывает `http://127.0.0.1:8080` в браузере по умолчанию |

По умолчанию сервер слушает **только 127.0.0.1** — доступен лишь с этого компьютера. Флаг `-Lan` открывает `0.0.0.0` и добавляет правило брандмауэра (нужны права администратора).

## Параметры

```bat
INSTALL_WINDOWS.bat -Port 9000
INSTALL_WINDOWS.bat -Lan
INSTALL_WINDOWS.bat -NoAutostart -NoTray
INSTALL_WINDOWS.bat -InstallDir D:\JARVIS
INSTALL_WINDOWS.bat -Update
INSTALL_WINDOWS.bat -Source C:\path\to\extracted\repo
INSTALL_WINDOWS.bat -Branch main
```

| Параметр | Meaning |
|---|---|
| `-Port <n>` | порт HUD (по умолчанию 8080) |
| `-Lan` | слушать всю локальную сеть + правило firewall |
| `-NoAutostart` | не добавлять в автозагрузку |
| `-NoTray` | без иконки в трее |
| `-NoLaunch` | не открывать браузер после установки |
| `-InstallDir` | другая папка установки |
| `-Source` | локальная папка с исходниками (оффлайн-установка) |
| `-Branch` | ветка GitHub для загрузки |
| `-PythonPath` | явный путь к `python.exe` |
| `-Update` | обновить файлы, сохранив данные и настройки |
| `-Silent` | без вопроса «Нажмите Enter» в конце |

## После установки

```
%LOCALAPPDATA%\JARVIS\
├── app\                    исходники приложения
│   ├── jarvis.config.json  настройки (в т.ч. API-ключ, если добавите)
│   └── .jarvis_data\       SQLite: заметки, задачи, напоминания
├── logs\                   server.log, agent.log
├── install.log             журнал установки
├── jarvis.ico
├── run-server.cmd / run-agent.cmd
├── start-background.vbs    скрытый запуск обоих сервисов
├── open-hud.vbs
├── restart-services.cmd / stop-services.cmd
└── tray.ps1                иконка в трее
```

Ярлыки: **Рабочий стол → J.A.R.V.I.S.**, меню Пуск → `J.A.R.V.I.S`, автозагрузка → `J.A.R.V.I.S. Background` и `J.A.R.V.I.S. Tray`.

## Обновление

Запустите `INSTALL_WINDOWS.bat` ещё раз из свежей папки с исходниками (или `-Update`). Установщик остановит старые процессы, обновит файлы и **сохранит** `.jarvis_data` и `jarvis.config.json`.

## Удаление

```bat
UNINSTALL_WINDOWS.bat              :: остановить сервисы, убрать ярлыки и автозагрузку; данные сохранятся
UNINSTALL_WINDOWS.bat -Purge       :: дополнительно удалить всю папку с данными (спросит подтверждение)
```

## Голос на Windows

- Распознавание: **Chrome или Edge** (Web Speech API), обязательно разрешите микрофон для `127.0.0.1`.
- Озвучивание: системные голоса SAPI. Если русского голоса нет — **Параметры → Время и язык → Речь → Добавить голоса → Русский**. Установщик предупредит об этом.
- Управление ПК (`app.open`, `file.*`, `clipboard.*`, `media.volume`, `screenshot`, `power.*`) выполняет `jarvis_agent.py`, который установщик запускает автоматически.

## Устранение неполадок

| Симптом | Что делать |
|---|---|
| Окно закрылось сразу | Запустите `INSTALL_WINDOWS.bat` из `cmd`, чтобы увидеть ошибку; смотрите `install.log` |
| `PowerShell` заблокировал скрипт | BAT уже использует `-ExecutionPolicy Bypass`; при ручном запуске добавьте этот флаг |
| HUD не открылся | `%LOCALAPPDATA%\JARVIS\logs\server.log`, затем `restart-services.cmd` |
| Агент не подключился | `logs\agent.log`; проверьте токен в `jarvis.config.json` и в команде агента |
| Порт 8080 занят | `INSTALL_WINDOWS.bat -Port 9000` |
| Нет русской озвучки | Добавить русский голос в Параметрах Windows (см. выше) |
| Нужно управление с телефона | `INSTALL_WINDOWS.bat -Lan` + узнать IP (`ipconfig`) + открыть `http://IP:8080` |

Все действия логируются в `%LOCALAPPDATA%\JARVIS\install.log`.
