# J.A.R.V.I.S. — голосовой AI-ассистент для управления ПК

> *«Just A Rather Very Intelligent System»* — говорите с компьютером, он отвечает, выполняет команды и помнит ваши дела.

Собрано с нуля на **чистом Python 3 (только стандартная библиотека)** и **vanilla JS** — без npm, без pip-зависимостей, без сборки. Всё работает сразу после `python jarvis.py`.

---

## ⚡ Быстрый старт

```bash
git clone https://github.com/Sevelin123/ASSISTENT-AI.git
cd ASSISTENT-AI
python jarvis.py
```

Откройте **http://localhost:8080** → нажмите **«Активировать систему»** → разрешите микрофон → скажите:

> **«Джарвис, который час?»**  
> **«Джарвис, открой YouTube»**  
> **«Джарвис, напомни через 10 минут про созвон»**

> Для распознавания речи нужен **Chrome или Edge** на `https://` или `localhost` (используется встроенный Web Speech API). В Firefox/Safari доступен текстовый ввод — весь остальной функционал работает.

## Архитектура: три части

```
┌────────────────────────┐      HTTPS / JSON + SSE      ┌──────────────────────────┐
│   Браузер (ваш HUD)    │ ───────────────────────────► │  jarvis.py (сервер/мозг) │
│  Web Speech API         │ ◄─────────────────────────── │  NLU / LLM / память /    │
│  микрофон + TTS + HUD   │      ответы, события         │  маршрутизатор действий  │
└────────────────────────┘                             └────────────┬─────────────┘
                                                                      │ задачи
                                                                      ▼
                                                       ┌──────────────────────────┐
                                                       │ jarvis_agent.py на ВАШЕМ │
                                                       │ ПК: открывает программы, │
                                                       │ файлы, звук, скриншоты   │
                                                       └──────────────────────────┘
```

1. **HUD** (`web/`) — голосовой ввод через `SpeechRecognition`, ответы через `speechSynthesis`, реактор-визуализатор на Canvas, телеметрия, лог диалога, настройки. Никаких запросов к `localhost` из браузера — только относительные URL к своему серверу.
2. **Мозг** (`jarvis/`) — распознаёт намерения, при наличии ключа советуется с LLM, выполняет серверные действия и диспетчеризует «компьютерные» действия агенту. Память на SQLite.
3. **Агент ПК** (`jarvis_agent.py`) — **один самодостаточный файл**, который вы запускаете у себя дома. Он подключается к серверу, получает задачи и выполняет их на реальной машине (Windows / macOS / Linux). Без агента сервер честно работает в **демо-режиме** (выполняет те же действия у себя, о чём сообщает в HUD).

Такое разделение нужно, потому что веб-страница физически не может запускать программы на вашем компьютере — это делает локальный агент.

## Подключение своего ПК (важнейший шаг)

В HUD откройте **Настройки → Агент управления ПК**, скопируйте команду и скачайте `jarvis_agent.py`:

```bash
# на вашем компьютере (Windows / macOS / Linux), Python 3.9+
python jarvis_agent.py --server https://ВАШ-АДРЕС-ПРЕВЬЮ
```

Агент сам зарегистрируется, и в HUD загорится **«ПК: <имя> подключён»**. С этого момента «открой блокнот», «громкость 40», «найди файл» и «скриншот» выполняются **на вашей машине**.

Дополнительные флаги:

```bash
python jarvis_agent.py --server http://localhost:8080 \
  --name "Мой ноутбук" \
  --root C:\Users\User \
  --allow-shell \      # разрешить команды терминала (по умолчанию ЗАПРЕЩЕНО)
  --allow-power        # разрешить выключение/перезагрузку (по умолчанию ЗАПРЕЩЕНО)
```

Агент можно запустить и на самом сервере: `python jarvis.py agent --server http://localhost:8080`.

## Мозг: оффлайн или LLM

**Без ключа (по умолчанию)** работает встроенный NLU: ~35 действий, правила на русском и английском, заметки, задачи, таймеры, калькулятор, системная информация, честные ответы на часть вопросов и пошаговое разложение задач. Никаких запросов в интернет.

**С языковой моделью** ассистент отвечает на любые вопросы, понимает сложные просьбы, переводит, пишет тексты и сам выбирает нужные действия. Поддерживается любой OpenAI-совместимый `/chat/completions`:

| Провайдер | `JARVIS_BASE_URL` | Модель |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.1-8b-instant` |
| **Ollama (локально, бесплатно)** | `http://localhost:11434/v1` | `llama3.1` |
| LM Studio | `http://localhost:1234/v1` | любая загруженная |

Проще всего — вкладка **Настройки → Мозг** в HUD (есть пресеты). Или через окружение:

```bash
export JARVIS_API_KEY=sk-...
export JARVIS_MODEL=gpt-4o-mini
python jarvis.py
```

Для Ollama ключ не нужен:

```bash
ollama pull llama3.1 && ollama serve
JARVIS_BASE_URL=http://localhost:11434/v1 JARVIS_MODEL=llama3.1 python jarvis.py
```

Ключ сохраняется только в локальном `jarvis.config.json` (в `.gitignore`) и никогда не отправляется в репозиторий.

## Голосовые режимы

| Кнопка | Режим | Поведение |
|---|---|---|
| **PTT** | Push-to-talk | Удерживайте **ПРОБЕЛ** или нажмите микрофон — скажите фразу, отпустите |
| **WAKE** | Wake word | Слушает постоянно, но реагирует только на «**Джарвис, …**» (слово меняется в настройках) |
| **LIVE** | Непрерывно | Каждая фраза сразу отправляется ассистенту |

Горячие клавиши: **Пробел** — говорить, **Ctrl+Shift+J** — включить/выключить LIVE, **Esc** — тишина (остановить речь и прослушивание), **?** — справочник команд.

Во время ответа микрофон автоматически приглушается, чтобы ассистент не слушал сам себя.

## Безопасность

Проект спроектирован так, чтобы голосом нельзя было случайно сломать систему:

- **Команды терминала и управление питанием выключены по умолчанию** и включаются отдельно и на сервере, и флагом агента.
- Опасные действия требуют голосового **«подтверждаю»** (или «отмена»); запрос живёт 3 минуты.
- Все файловые операции ограничены домашней папкой / `--root`, выход за пределы блокируется.
- Запрещены опасные шаблоны в shell (`rm -rf`, `mkfs`, `dd if=`, `:(){`, `curl | sh`, …), есть таймауты.
- Все действия логируются в SQLite и видны в HUD; API-ключ не попадает в логи и в git.
- Реестр действий жёстко фиксирован: LLM не может придумать и выполнить неизвестную команду.

> Если вы публикуете сервер в открытый интернет, поставьте его за авторизацией/туннелем с доступом только для себя: API конфигурации позволяет менять настройки без пароля.

## HTTP API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/chat` | `{text, source}` → `{reply, actions[], mode, agent}` |
| `GET` | `/api/status` | мозг, агент, статистика, платформа |
| `GET` | `/api/telemetry` | CPU / RAM / диск (с ПК, если агент подключён) |
| `GET` | `/api/history` · `DELETE /api/history` | история диалога |
| `GET` · `POST` | `/api/config` | настройки (ключ не возвращается) |
| `GET` | `/api/catalogue` | все действия и описания |
| `GET` | `/api/reminders` | активные напоминания |
| `GET` | `/api/events` | SSE: `speak`, `agent`, `config`, `action`, `chat` |
| `POST` | `/api/agent/register` · `/poll` · `/result` · `/heartbeat` | протокол агента |
| `GET` | `/download/jarvis_agent.py` | скачать агент одним файлом |

Пример:

```bash
curl -s -X POST http://localhost:8080/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"text":"Джарвис, посчитай 2+2*10"}'
```

## Известные ограничения (честно)

- **Распознавание речи** — браузерный Web Speech API: нужен Chrome/Edge и интернет-соединение (обработка идёт через движок браузера). Для полностью оффлайн-распознавания можно заменить `VoiceIn` в `web/app.js` на локальный Vosk/Whisper-сервис — остальной код менять не нужно.
- **Синтез речи** — голоса операционной системы. Если русского голоса нет, установите его в ОС или выберите доступный в Настройках.
- **Без LLM** свободные вопросы ограничены встроенной базой знаний; команды ПК работают полностью.
- **Веб-страница не может напрямую управлять ПК** — для реального управления нужен `jarvis_agent.py`. Это ограничение браузера, а не проекта.
- В headless-среде (например, облачной песочнице) часть действий вернёт честное «устройство недоступно» — на вашем ПК с агентом они выполнятся.

## Расширение

Добавить команду — одна строка в `jarvis/nlu.py`:

```python
(r"(выключи свет|lights off)", lambda t, m: I("app.open", target="http://...")),
```

Добавить новое действие — запись в `ACTIONS` (`jarvis/skills/base.py`), обработчик в `jarvis/skills/local_ops.py` (после чего пересоберите `jarvis_agent.py`, скопировав туда функцию) и, при необходимости, в `SERVER_HANDLERS`.
